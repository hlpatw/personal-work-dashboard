# 旺达工作台 · 思维导图

> 本文件可用 [Markmap](https://markmap.js.org/repl) 直接粘贴渲染，或导入 XMind（Markdown 模式）。
> 更新至 v1.4.0（2026-10-18：氛围层 + 柯基 AI 增强）。

```markmap
# 旺达工作台

## 功能模块
### 概览 `/`
- 今日统计卡片
  - 今日待办 / 进行中
  - 今日完成 + 完成率进度环
  - 今日日程数
- 逾期红色角标提醒
- 今日 + 逾期任务
  - 一键勾选完成
- 今日日程时间线
- 此刻灵感快捷记录区
- 今日已完成清单

### 任务 `/tasks`
- 任务管理
  - 新建 / 编辑 / 删除（模态框）
  - 整块点击即编辑
  - 状态流转：待办 → 进行中 → 已完成
- 属性
  - 分类：工作 / 学习 / 生活 / 其他（彩色徽章）
  - 优先级：紧急 / 高 / 中 / 低（彩色圆点）
  - 截止日期（逾期红显，新建默认当天）
  - 预计时长 / 描述备注
- 子任务清单
- 关联长期目标（进度聚合）
- 标签：五项快选（重要/今日待办/待定/已延期/需确认）+ 自定义
- 贴图：选图或 Ctrl+V 粘贴截图
- 筛选：关键词 / 状态 / 分类 / 标签 / 目标

### 日历 `/calendar`
- 月历视图（周一起始，6×7 格）
- 日程色条（每日最多显示 2 条）
- 单击选中日 / 双击日期快速新建
- 全天 / 定时日程、地点、备注
- 选中日详情面板（点击即编辑）
- 翻月 / 回今天

### 此刻灵感 `/inspirations`
- 常驻输入框，回车即记
- 时间流卡片 + 类型徽章（灵感/工作/生活/心情）
- 全文搜索 / 类型筛选
- 一键转任务
- 贴图 + 卡片原地编辑（带"已编辑"标记）

### 目标 `/goals`
- 长期目标：进度聚合（关联任务完成度）
- 剩余天数（临期 / 逾期变色）
- 状态流转：进行中 / 已完成 / 已归档
- 分类徽章 / 贴图 / 整卡点击即编辑

### 统计 `/stats`
- 每周自动周报卡
  - 本周完成 / 环比 / 最活跃日
  - 分类变化 / 逾期提醒
  - 「让柯基点评」流式点评
- 汇总卡片：总完成率 / 本周完成 / 逾期 / 总数 / 完成目标
- 每周完成数柱状图（近 12 周，峰值标注）
- 分类分布环形图（4 色 + 图例）
- 分类明细表（迷你进度条）

## 柯基 AI 助手
- 右侧可折叠聊天侧栏（36px 把手 / 320px 面板）
- 纯自定义 OpenAI 兼容接口
  - 地址 / 模型 / Key 仅存浏览器 localStorage
  - 后端零感知凭据，仅转发绕 CORS
- 流式输出（SSE 透传，逐字打出）
- 今日安排：发送时注入今日任务/日程快照（chip 可开关）
- 空对话快捷指令「帮我安排今天」
- 柯基人格可自定义（系统提示词）
- Markdown 渲染（过滤 script/事件属性）
- 聊天历史持久化 + 一键新对话

## 视觉体系（v1.4.0 氛围层）
- 单一色相粉：玫红 351/89 四档明度（全站只有一种粉）
- 三层氛围背景（纵深渐变 + 左上冷光 + 右上品牌光）+ 颗粒质感
- 玻璃卡片 / 磨砂侧栏 / 亮一档弹窗
- 精致模式：圆角 14、4px 进度条、侧栏指示条、tabular-nums
- 深色 ⇄ 浅色双主题，刷新不闪烁
- 图表颜色随主题联动（色盲安全验证）

## 桌面与分发
- 像素柴犬桌宠（Electron）
  - 悬停激活 / 点击开面板 / 按住拖动
  - 平时点击穿透不挡窗口
- NSIS 安装包（npm run dist 一键打包）
- 桌面版后端进程内运行（端口 3210）
- 安装版数据独立存 %APPDATA%\desktop\data

## 技术架构
### 前端 client/
- React 19 + Vite + TypeScript
- Tailwind CSS v4（dark class 变体）
- TanStack Query（服务端状态缓存）+ zustand persist
- recharts（图表）+ date-fns（中文日期）
- 单一色相体系 = @theme 色阶重映射（工具类自动跟随）

### 后端 server/
- Express 5 + zod 校验
- node:sqlite（Node 内置，零原生依赖，WAL 模式）
- 表：tasks / schedules / goals / inspirations / subtasks / users
- 多账号预留：user_id 外键 + 用户中间件接缝
- AI 转发路由：SSE 透传 + 非流式降级 + 三层超时
- 测试：vitest + supertest（45 用例，内存库）

### 验收与工具
- 浏览器验收：playwright-core + 系统 Chrome
- scripts/verify-ui.mjs（UI 基线）
- scripts/atm-verify.mjs（氛围层：双主题截图 + 色相审计）
- scripts/verify-corgi.mjs（AI 链路：mock SSE 上游）
- npm run seed 示例数据 / npm run reset 清空
```
