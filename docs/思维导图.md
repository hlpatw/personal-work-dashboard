```markmap
# 个人工作面板

## 功能模块
### 概览 `/`
- 今日统计卡片
  - 今日待办 / 进行中
  - 今日完成 + 完成率
  - 今日日程数
- 逾期红色提醒（数量角标）
- 今日 + 逾期任务
  - 一键勾选完成
- 今日日程时间线
- 今日已完成清单

### 任务 `/tasks`
- 任务管理
  - 新建 / 编辑 / 删除（模态框）
  - 状态流转：待办 → 进行中 → 已完成
- 属性
  - 分类：工作 / 学习 / 生活 / 其他
  - 优先级：紧急 / 高 / 中 / 低（彩色圆点）
  - 截止日期（逾期红显）
  - 描述备注
- 筛选与搜索
  - 关键词（标题+描述）
  - 按状态 / 按分类
- 排序：状态 → 优先级 → 截止日

### 日历 `/calendar`
- 月历视图（周一起始，6×7 格）
- 日程色条（每日最多显示 2 条）
- 选中日详情面板
  - 全天 / 定时日程
  - 地点、备注
  - 新增 / 编辑 / 删除
- 翻月 / 回今天

### 统计 `/stats`
- 汇总卡片
  - 总完成率 / 本周完成
  - 逾期任务 / 任务总数
- 每周完成数柱状图（近 12 周，峰值标注）
- 分类分布环形图（4 色 + 图例）
- 分类明细表（数字右对齐）

## 技术架构
### 前端 client/
- React 19 + Vite + TypeScript
- Tailwind CSS v4（dark class 变体）
- TanStack Query（服务端状态缓存）
- zustand（主题，localStorage 持久化）
- recharts（图表）+ date-fns（中文日期）
- Vite 代理 /api → 3001

### 后端 server/
- Express 5 + zod 校验
- node:sqlite（Node 内置，零原生依赖）
- 表：tasks / schedules（WAL 模式）
- REST API：/api/tasks、/api/schedules、/api/stats
- 种子脚本 seed.ts

### 测试与工具
- 后端：vitest + supertest（18 用例，内存库）
- 浏览器验收：scripts/verify-ui.mjs
- 生产构建：npm run build

## 主题
- 深色（默认）⇄ 浅色
- 侧栏一键切换
- 刷新保持、无首屏闪烁
- 图表颜色随主题联动（色盲安全验证）

## 数据
- SQLite 文件：server/data/dashboard.db
- 重启不丢失
- npm run seed 重置示例数据
```
