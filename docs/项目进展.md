## 项目一句话

个人工作面板：任务待办 + 日程日历 + 长期目标 + 数据统计，带桌面小宠物（像素柴犬），粉/暗双主题，全中文，单机使用（多账号架构已预留）。

## 技术栈与结构（详见 README.md）

- 前端：React 19 + Vite + TS + Tailwind v4 + TanStack Query + zustand + recharts（client/）
- 后端：Express 5 + Node 内置 node:sqlite（server/），端口 3001
- 桌面：Electron（desktop/），`npm run desktop` 启动像素狗宠物，`npm run dist` 打安装包
- 测试：server 24 个 API 用例（vitest + supertest）+ scripts/ 下的浏览器验收脚本模式

## 已完成的功能（截至 2026-10-02）

1. **四+一 页面**：概览（Bento 卡片+进行中目标）/ 任务（筛选/标签/子任务/关联目标/预计时长）/ 日历 / 目标（进度聚合/剩余天数）/ 统计（周柱状图/分类环形图）
2. **桌面宠物**：像素柴犬，两帧动画（常态垂耳/兴奋竖耳吐舌），点击开关联换面板、按住拖动（Pointer Capture + IPC 合帧节流）、右键菜单
3. **设计语言**：Plane 式暗色专业风（近黑 #0e0e11 亮度分层）+ 玫瑰粉唯一强调色；浅色为同体系灰白版
4. **多账号预留**：users 表 + user_id 外键 + 用户中间件接缝（单机版恒为 id=1），上线多账号只需替换中间件
5. **数据**：SQLite 自动迁移，npm run seed 演示数据 / npm run reset 清空

## 用户偏好（重要！）

- **审美**：喜欢精致、克制、专业的风格；最终确认的是"Plane 暗色专业风 + 玫瑰粉强调色"

## 踩过的坑（别再踩）

1. Electron 主进程 spawn 子进程：带中文的绝对路径参数会静默失败 → 用 cwd + 纯 ASCII 相对路径
2. 后端启动窗口期内探测端口会让进程挂死 → 只能监听子进程启动日志（事件驱动）
3. pet.html 里不能 `const desktop`（与 contextBridge 注入的全局标识符冲突，整块脚本解析失败）→ 用别名 `bridge`
4. 拖动透明窗口的残影 → IPC 合帧节流 + backgroundThrottling: false + setOpacity(0.99999)
5. Electron 固定版本号才能打包（"39.8.10" 而非 "^39.0.0"）
6. 透明窗口渲染不稳 → 曾用 disableHardwareAcceleration 救急，后来不需要了（保留注释在 main.js）

## 验证方式

- `npm test`（后端 24 用例）、`npm run build`（前端类型+打包）
- 浏览器验收脚本模式：scripts/ 下写过多次（playwright-core + 系统 Chrome），套路是"临时 seed 数据 → 截图/DOM 断言 → reset 清空"
- 桌面自检：`$env:ELECTRON_SHOT_DIR="..."; npm run desktop` 自动截图退出
- 图像审查工具（zai analyze_image）在部分会话可用，不可用时用像素采样/DOM 断言替代（有现成范例可参考 git log）
